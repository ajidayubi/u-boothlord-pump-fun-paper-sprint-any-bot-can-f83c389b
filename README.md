A fresh-surge momentum bot for pump.fun paper trading: it buys a bonding curve only when a crowd is visibly arriving (several distinct buyers, net SOL flowing in, price climbing near its recent high and accelerating), starts with a small buy, adds into strength, and exits whole on a stop loss, a trailing stop, a fade, or a time limit. Deterministic: no clock, no environment, no randomness.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/replay/v2 on stdin/stdout (hello, batch, done) via the vendored SDK shim in `vendor/makefun-bot.ts`. It runs on Node 22 with nothing to install.
